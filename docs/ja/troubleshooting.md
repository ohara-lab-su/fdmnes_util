# トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| `fdmnes_util` が見つからない | インストールに使った仮想環境を有効にします。 |
| 入力ファイルが見つからない | 作業ディレクトリと `-i` を確認します。`fdmfile.txt` があれば先頭ジョブも確認します。 |
| `*_conv.txt` や `*_sd0.txt` がない | `Filout`、サイト番号、計算時の出力設定を確認します。描画スクリプトはFDMNESの計算を実行しません。 |
| BAVのリビジョンが未確認 | SDの列レイアウトが確認できている場合は `--year 2016` または `--year 2020` を明示します。 |
| SDでスピン指定が拒否される | 確認済みの2020年SD形式は単一スピンです。2016年形式では入力とファイルのスピン数を一致させます。 |
| 平均化で格子不一致になる | 同種のファイルのエネルギー列を比較してください。補間が必要な場合は、物理的に妥当な共通格子を選び、平均前に明示的に補間します。 |
| 吸収端・Fermi準位が予想と違う | 生XASのヘッダと `Energpho`、`--fermi`、`--nonsubtract` の組合せを確認します。 |
| GUIが利用できない | 対応するサンプルで `--nw` を使い、必要に応じて `MPLBACKEND=Agg` を設定します。 |
| POSCAR変換でimportエラー | `vasp-util` とASEのインストール先を確認します。 |
| SphinxがPythonモジュールを読み込めない | ビルド用Python環境にプロジェクトと `docs/requirements.txt` を入れます。 |

報告には、使用したコマンド、FDMNESリビジョン、入力キーワード、該当出力の列ヘッダ、エラーメッセージを添えてください。
