# Rebuild v17 — ファイル形式単位へのクラス統合

## 今回変更した範囲

- `read_*.py` / `write_*.py` という操作別の命名をやめ、`fdm_inp.py`、`fdmfile.py`、`fdm_bav_2016.py`、`fdm_sd_2020.py` など、ファイル形式と年度を表すモジュール名に変更。
- クラス名の `Read` / `Write` 接頭辞を廃止。例: `FdmInp`、`Fdmfile`、`FdmBav2016`、`FdmSd2020`。
- `.inp` の読み込みと書き出しを `FdmInp` に統合。`fdmfile.txt` の読み込みと書き出しを `Fdmfile` に統合。構造セクション、XYZ、光電子エネルギーの出力専用機能もファイル・内容に基づく命名へ変更。
- SAE原本 `sae/fdmnes/` の存在を再確認し、該当する形式別モジュールの先頭に原本のヘッダコメントを移植。2016/2020の履歴を区別。
- ライブラリ、サンプルスクリプト、テストのimportを新しいクラス名とモジュール名へ変更。旧互換モジュールは作成していない。
- `fdmnes_util install script` のエントリーポイント、`pyproject.toml`、外部 `vasp_util` の利用を維持。
